# LedBox — site público

Páginas públicas do jogo LedBox (GitHub Pages): política de privacidade, suporte e exclusão de dados.
O código do jogo fica em outro repositório (privado).

- `privacy.html` — política de privacidade (inglês e português). Link usado no Play Console.
- `delete.html` — como pedir a exclusão da conta e dos dados (exigência do Google Play).
- `support.html` + `support.js` — formulário de suporte. As respostas vão para um Google Forms
  (configurar `FORM_ACTION` e os `entry.NNN` no topo do `support.js`); sem isso, abre o e-mail já preenchido.

E-mail de contato: ledboxsupport@gmail.com (em `privacy.html`, `delete.html` e `support.js`).
